## 2) النشر على Railway (الموصى بها — بلا بطاقة، تحديث تلقائي)

1. سجّل بحساب GitHub على [railway.com](https://railway.com) → **Login** —
   تجربة مجانية فورية $5 لمدة 30 يوم، **بدون بطاقة** (تحقق GitHub التلقائي يؤهّلك للنطاق الكامل).
2. **New Project → Deploy from GitHub repo** → اختر `ali2024sh/sh-Ai` والفرع `main`.
3. Railway يكتشف `Dockerfile` تلقائياً ويبني ويشغّل.
4. أضف **المتغيرات**: `GEMINI_API_KEY` (Secret)، `EDUI_SEED_DEMO=1`.
   (منفذ الاستماع يضبطه Railway تلقائياً عبر `PORT`.)
5. أضف **Domain** لتصل من أي مكان → رابط `*.up.railway.app`.
6. **Autodeploy** مفعّل افتراضياً: أي `git push` إلى `main` يُعيد البناء والنشر فوراً.

> بعد 30 يوم أو استهلاك $5: تتحول تلقائياً لخطة **Free** بائتمان $1/شهر
> تكفي خدمة صغيرة تعمل 24/7 تقريباً؛ عند نفاد الائتمان تتوقف الخدمة حتى تجدّد.
> الخدمة تعمل باستمرار (لا تنام) ما دام الائتمان متاحاً.

## 3) النشر على Render (إن وُجدت بطاقة أو حساب قديم)

### الطريقة A — بضغطة واحدة (المستودع عام)
```
https://render.com/deploy?repo=ali2024sh/sh-Ai
```
→ اختر الفرع `main` → سيكتشف `render.yaml` وينشئ الخدمة.

### الطريقة B — عبر Blueprint يدوياً
1. **New → Blueprint** → اختر المستودع `ali2024sh/sh-Ai`.
2. بعد الإنشاء: **Environment → Add Environment Variable** لـ `GEMINI_API_KEY` الحقيقي.
3. خدمة مجانية تنام ~15 دقيقة وتستيقظ عند أول طلب (~50 ثانية).

---

## 4) ملاحظات مهمة (شفافية)
- **التخزين**: نستخدم SQLite. في الخطط المجانية يُمسح القرص عند إعادة النشر،
  لذلك تُعاد بذر البيانات التجريبية تلقائياً — مثالية للعرض، وغير مناسبة
  لإنتاج طويل الأمد (يحتاج قاعدة Postgres أو قرصاً دائماً).
- **المفتاح**: بدون `GEMINI_API_KEY` حقيقي، توليد الملخص/الاختبار/الدردشة يعرض
  رسائل توجيهية عربية مقصودة، وكل شيء آخر يعمل.
- **النطاق المخصص**: بعد النشر يمكن ربط نطاقك الحر أو المدفوع من لوحة المنصة.

## 5) التحقق بعد النشر
افتح الرابط في المتصفح، ثم:
- سجّل الدخول بالحساب التجريبي (يظهر مستند + اختبار + فريق).
- افتح `https://<your-app>/api/health` — يتوقع JSON يعرض `status: ok`.
- لوحة API التفاعلية: `https://<your-app>/docs`.
