# دليل استضافة ذكاء | EduAI (Koyeb / Railway / Render)

النشر مجاني، ويشغّل **حزمة واحدة**: خادم FastAPI يقدّم الواجهة المبنية + `/api`.
تحديث تلقائي: كل `push` إلى فرع `main` في GitHub يعيد البناء والنشر فوراً.

## 2) النشر على Koyeb (الموصى بها — بلا بطاقة)

1. سجّل بحساب GitHub على [app.koyeb.com](https://app.koyeb.com) → **Sign up with GitHub** (يمكن أن يطلب البريد/التحقق فقط، لا بطاقة).
2. ثبّت تطبيق **Koyeb (GitHub App)** ومنحه الوصول لمستودعك `ali2024sh/sh-Ai`.
3. في اللوحة: **Apps → Create App**.
4. اختر مصدر النشر **GitHub** → اختر المستودع `ali2024sh/sh-Ai` والفرع **`main`**.
5. في **Builder** اختر **Dockerfile** (يكتشف `Dockerfile` من جذر المستودع تلقائياً).
6. **Environment variables / Secrets**:
   - `GEMINI_API_KEY` = مفتاحك الحقيقي (كـ **Secret**).
   - `EDUI_SEED_DEMO` = `1` (بذر البيانات التجريبية عند أول تشغيل).
   - (اختياري) `PORT` = `8000`.
7. **Ports** → أضف المنفذ: 8000 → بروتوكول `http` → المسار `/`.
   (إن لم تضبط `PORT` فاستخدم 8001 بدلاً منها — هو الافتراضي في الصورة.)
8. **Deploy** → انتظر البناء (قد يستغرق أول مرة 5–10 دقائق) → سيعطيك رابطاً مثل `https://eduai-<youruser>-<app>.koyeb.app`.

**التحديث التلقائي**: خدمة موصولة بمستودعك بها خيار **Autodeploy** مفعل افتراضياً —
أي `git push` إلى `main` يعيد البناء والنشر. (تأكد أن Autodeploy ✓ في إعدادات الخدمة.)

> الخطة المجانية تعلّق الخدمة بعد 30 يوم **بدون نشاط على حسابك** — زوّر نفسك للوحة
> أو ادفع تحديثاً ولن يتوقف شيء. الزوّار لا يوقفوها (تشتغل 24/7).

## 3) النشر على Railway (بديل بلا بطاقة)

1. [railway.com](https://railway.com) → **Login** (تسجيل GitHub) — تجربة مجانية $5 لمدة 30 يوم بلا بطاقة.
2. **New Project → Deploy from GitHub repo** → اختر `ali2024sh/sh-Ai` والفرع `main`.
3. Railway يكتشف `Dockerfile` تلقائياً.
4. المتغيرات: `GEMINI_API_KEY`، `EDUI_SEED_DEMO=1` (وربما `PORT`).
5. أضف **Domain** لكي تصل من أي مكان → رابط `*.up.railway.app`.
6. Autodeploy مفعل افتراضياً عند كل push.

---

## 4) النشر على Render (إن وُجدت بطاقة أو حساب قديم)

### الطريقة A — بضغطة واحدة (المستودع عام)
```
https://render.com/deploy?repo=ali2024sh/sh-Ai
```
→ اختر الفرع `main` → سيكتشف `render.yaml` وينشئ الخدمة.

### الطريقة B — عبر Blueprint يدوياً
1. **New → Blueprint** → اختر المستودع `ali2024sh/sh-Ai`.
2. بعد الإنشاء: **Environment → Add Environment Variable** لـ `GEMINI_API_KEY` الحقيقي.
3. خدمة مجانية تنام ~15 دقيقة وتستيقظ عند أول طلب (~50 ثانية).

## 5) ملاحظات مهمة (شفافية)
- **التخزين**: نستخدم SQLite. في الخطط المجانية يُمسح القرص عند إعادة النشر،
  لذلك تُعاد بذر البيانات التجريبية تلقائياً — مثالية للعرض، وغير مناسبة
  لإنتاج طويل الأمد (يحتاج قاعدة Postgres أو قرصاً دائماً).
- **المفتاح**: بدون `GEMINI_API_KEY` حقيقي، توليد الملخص/الاختبار/الدردشة يعرض
  رسائل توجيهية عربية مقصودة، وكل شيء آخر يعمل.
- **النطاق المخصص**: بعد النشر يمكن ربط نطاقك الحر أو المدفوع من لوحة المنصة.

## 6) التحقق بعد النشر
افتح الرابط في المتصفح، ثم:
- سجّل الدخول بالحساب التجريبي (يظهر مستند + اختبار + فريق).
- افتح `https://<your-app>/api/health` — يتوقع JSON يعرض `status: ok`.
- لوحة API التفاعلية: `https://<your-app>/docs`.
