# دليل استضافة ذكاء | EduAI (Render / Railway)

النشر مجاني تقريباً، ويشغّل **حزمة واحدة**: خادم FastAPI يقدّم الواجهة المبنية + `/api`.

## 1) المتطلبات القبلية
- حساب [GitHub](https://github.com) ومشروعك مرفوع عليه (يوجد: `main` يحتوي كل التحديثات).
- حساب على [Render](https://render.com) أو [Railway](https://railway.app) (يمكن التسجيل بحساب GitHub).
- (اختياري لكن ضروري لمزايا الذكاء الاصطناعي) مفتاح Google Gemini: https://aistudio.google.com/apikey

---

## 2) النشر على Render (الطريقة الموصى بها)

### الطريقة A — عبر Blueprint (تلقائية بالكامل)
0. **بضغطة واحدة** (المستودع عام): افتح
   `https://render.com/deploy?repo=ali2024sh/sh-Ai`
   → اختر الفرع **`main`** → سيكتشف `render.yaml` وينشئ الخدمة.
1. (أو يدوياً) في لوحة Render: **New → Blueprint** → اختر المستودع `ali2024sh/sh-Ai`.
   Render سيكتشف `render.yaml` وينشئ الخدمة تلقائياً.
3. بعد الإنشاء: **Environment → Add Environment Variable**:
   - `GEMINI_API_KEY` = مفتاحك الحقيقي (بدونه تعمل المنصة لكن التوليد يعرض رسالة توجيهية).
   - `EDUI_SEED_DEMO` = `1` (بذر البيانات التجريبية عند أول تشغيل).
4. خدمة مجانية; ستنام بعد ~15 دقيقة خمول وتستيقظ عند الطلب (أول فتح يستغرق ~50 ثانية).

### الطريقة B — يدوياً (Web Service)
1. **New → Web Service** → اتصل بمستودعك → اختر `ali2024sh/sh-Ai`.
2. خيار **Runtime**: سيُکتشف `Dockerfile` تلقائياً (اختر **Docker** إن لم يُكتشف).
3. **Environment Variables**: أضف `GEMINI_API_KEY` (اختياري)، و`EDUI_SEED_DEMO=1`.
4. **Create Web Service** → انتظر البناء (قد يستغرق 5-10 دقائق في أول مرة).
5. بعد الجاهزية افتح الرابط المعطى مثل `https://eduai.onrender.com`.

> متغير `PORT` يضبطه Render تلقائياً; خادمنا يستمع عليه.

### بيانات العرض التجريبي (تُبذر تلقائياً عند أول تشغيل)
| الدور | البريد | كلمة المرور |
|---|---|---|

## 3) النشر على Railway

1. ادفع مشروعك إلى GitHub أو استخدم **Railway CLI**:
   ```
   railway link
   railway up
   ```
2. أو: **New Project → Deploy from GitHub repo** → اختر `ali2024sh/sh-Ai`.
3. أضف متغيرات البيئة نفسها أعلاه (`GEMINI_API_KEY`, `EDUI_SEED_DEMO=1`).
4. Railway يكتشف `Dockerfile` ويشغّله. احصل على رابط `*.up.railway.app`.

---

## 4) ملاحظات مهمة (شفافية)
- **التخزين**: نستخدم SQLite على قرص الأغلفة. في الخطط المجانية لـ Render/Railway يُمسح القرص عند
  إعادة النشر/إيقاف الخدمة، لذلك تُعاد بذر البيانات التجريبية تلقائياً — مثالية للعرض،
  وغير مناسبة لإنتاج حقيقي طويل الأمد (يتطلب PostgreSQL أو قرصاً مدفوعاً).
- **المفتاح**: بدون `GEMINI_API_KEY` صحيح، توليد الملخص/الاختبار/الدردشة يعرض رسائل توجيهية
  عربية (تصميم مقصود تحقّقنا منه)، وكل شيء آخر يعمل.
- **النطاق المخصص**: بعد النشر يمكنك ربط نطاق حر أو مدفوع من لوحة العرض.

## 5) التحقق بعد النشر
افتح مرة واحدة على الأقل في المتصفح، ثم:
- سجّل الدخول بالحساب التجريبي (يظهر مستند + اختبار + فريق).
- افتح `https://<your-app>/api/health` — يتوقع JSON يعرض `status: ok`.
- لوحة API التفاعلية: `https://<your-app>/docs`.
